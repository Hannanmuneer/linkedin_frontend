# LinkedIn Clone (React + Tailwind)

Login, Signup and Login Successful pages.

## Run
```
npm install
npm run dev
```
Open http://localhost:5173

## Structure
```
src/
  main.jsx              entry (Router + AuthProvider)
  App.jsx               routes (/login, /signup, /success)
  context/AuthContext   login / signup / logout state
  components/           Logo, Field, GoogleButton, Divider, Footer
  pages/                Login, Signup, Success
```
